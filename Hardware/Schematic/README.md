# Schematic Source

Native Altium Designer schematic for the L298N motor driver board. The original file is retained without design edits.

## Initial source inspection

The component records identify an L298N motor driver, an L7805CV regulator, eight 1N4007 diodes, three polarized capacitors, an LED, a resistor and five headers. Net labels include VCC, +5, GND, EN1/EN2, IN1–IN4 and OUT1–OUT4.

This is an inventory-level inspection of the native source, not a full electrical rules check or a net-by-net verification. Detailed pin connectivity, component ratings and ERC results have not yet been independently verified. Fabrication and successful functional testing are reported by the designer.
